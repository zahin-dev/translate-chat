# 翻訳チャット / Translate Chat

日本語話者と英語話者の友人が、同じ部屋で会話するローカルWebアプリです。「翻訳チャット」は内容を表す仮の表示名で、正式なアプリ名は未決定です。

ローカル版は完成し、[GitHubでソースを公開](https://github.com/zahin-dev/translate-chat)しています。[自動テストとコンテナビルド](https://github.com/zahin-dev/translate-chat/actions/runs/39104069979)も成功しました。Vercelの新規プロジェクトは作成済みで、Neonの接続とアプリURLでの検証が残っています。構成と手順は [公開の進め方](DEPLOYMENT.md) を参照してください。

## 起動する

このPCでの初回準備は完了しています。PowerShellで実行します。

```powershell
cd path\to\translate_app
.\Start-App.ps1
```

起動後、**PC版Chromeで http://localhost:8080/** を開きます。終了するときは、起動したPowerShellで `Ctrl + C` を押します。

別のWindows PCで初めて準備する場合は、最初に `Setup.ps1` を実行します。Java・Maven・PostgreSQLと必要なライブラリをダウンロードします。道具はこのフォルダの `.tools/` に配置し、Windows全体のPATHやデータベースサービスの登録は変更しません。

PostgreSQLはアプリ終了後も起動を維持します。停止する場合は、アプリを終了した後に実行します。

```powershell
.\Stop-Database.ps1
```

## 使い方

ホーム画面右上の「日本語 / English」で画面の表示言語を切り替えると、「メッセージを読む言語」も同じ言語になります。その後、読む言語だけを手動で変えることもできます。初期表示は日本語で、選択は同じブラウザに保存されます。切り替えても、入力中の名前・ルームIDは残ります。

拡大時は見出しを折り返し、チャットの入力欄が画面内に収まるよう調整します。スクロールバーは表示しませんが、会話履歴やメンバー欄はホイール・タッチパッド等でスクロールできます。

チャット画面のサイドバーと会話の境界をドラッグすると幅を変えられます。境界にフォーカスして左右キーでも調整でき、ダブルクリックで既定幅に戻せます。選んだ幅は同じブラウザに保存されます。

1. 表示名と、メッセージを読む言語（日本語・English）を選びます。
2. 「部屋を作る」を選び、自動発行されたルームIDを友人に伝えます。
3. 友人は「部屋に参加」から同じIDを入力します。2人でも複数人でも会話できます。
4. 普段の言語で送信します。相手のメッセージは、読む人のPC内で翻訳されます。
5. 「原文を見る」で元の文章を確認できます。退出しても、再入室すると履歴を読めます。

1台のPCで試す場合は、Chromeの別タブを開き、別の表示名・言語で参加してください。`localhost` はこのPCだけのアドレスです。海外の友人から接続するためには、後のクラウド公開が必要です。

画面を再読み込みすると、そのタブの参加情報で会話を再開します。明示的に退出してから参加すると新しい参加者として扱います。表示名だけで本人確認はしません。

## 翻訳について

- PC版ChromeのTranslator APIを使います。翻訳サービスの契約・APIキー・カード登録は不要です。
- 初回は翻訳用データをダウンロードします。準備・翻訳に失敗しても原文での会話を続けられ、「翻訳を準備する／再試行」から準備をやり直せます。
- 自分の発言は原文、相手の発言は選択した言語で表示します。
- 入力言語はChromeの言語判定を利用し、不明確な短文等では文字種で補います。読む言語と入力言語は別に扱います。日英混在や固有名詞では判定・翻訳が不自然になることがあります。
- 原文はアプリのサーバー・PostgreSQLに保存します。翻訳結果はブラウザのメモリに一時保持し、外部翻訳サービスには本文を送りません。
- 検証では口調が不自然になる例もありました。必要に応じて原文を確認してください。
- スマートフォンでの自動翻訳は今回の対応範囲に含みません。

参考：[Chrome公式のTranslator API説明](https://developer.chrome.com/docs/ai/translator-api)

## 技術とファイル

| 部分 | 使用するもの |
|---|---|
| サーバー | Java 21 / Spring Boot 3.5.16 |
| 画面 | HTML / CSS / JavaScript |
| 会話履歴 | PostgreSQL 18.6（ローカル専用のポータブルバイナリ） |
| ビルド | Maven 3.9.16 |
| テスト | JUnitと実際のHTTP・PostgreSQL、Node.js標準テストによる翻訳処理の異常時確認 |

- `src/main/java/jp/translatechat/`：部屋・会話・入力確認・アクセス制御。
- `src/main/resources/static/`：画面、画面操作、翻訳処理。
- `src/main/resources/schema.sql`：保存する表の定義。
- `src/test/`、`tests/`：自動テスト。
- `week1/`：要件定義書・基本設計書。
- `.tools/`：このプロジェクトで使う道具とライブラリ。Gitの対象外。
- `.local/`：PostgreSQLのデータと開発用の接続情報。Gitの対象外。削除すると履歴等を失います。

JavaはEclipse Temurin、MavenはApache、PostgreSQLバイナリはMaven CentralのZonky配布を利用し、取得時にチェックサムを照合します。Dockerは使用しません。

アプリは `127.0.0.1:8080`、PostgreSQLは `127.0.0.1:55432` で動きます。DB接続用パスワードは初回に生成し、`.local/database-password.txt` から起動プロセスへ渡します。接続情報や履歴をGitHubに含めないでください。

## 実装上の初期値

次はローカル版を動かすために選んだ初期値で、本人の恒久的な仕様合意とは区別します。

| 項目 | 現在の動作 |
|---|---|
| ルームID | 推測しにくいランダムな12文字。4文字ずつ区切って表示。 |
| 入力制限 | 表示名30文字、メッセージ2,000文字以内。 |
| 新着の取得 | 2秒ごとに追加分を取得。 |
| 参加中の表示 | 明示的な退出、または約45秒通信がない参加者を参加中一覧から外す。 |
| 履歴 | 最近100件から表示し、「以前の会話を読む」で過去へさかのぼる。 |
| 再送 | 送信の識別子を使い、同じ送信を重複保存しない。 |
| 連続操作 | 参加は接続元ごとに毎分30回、送信は参加者ごとに毎分60回まで。 |
| 見た目 | 白系の背景と緑を使った仮デザイン。本人の好みとしては未確定。 |

部屋の期限・履歴の自動削除・管理画面・メッセージ編集は未実装です。ルームIDを知る人は過去の会話も読めます。

## テストする

```powershell
.\Test-App.ps1
```

JUnitは別のデータベース `translate_chat_test` を使います。翻訳処理のテストにはインストール済みのNode.jsを使い、外部翻訳APIは呼びません。

2026年10月18日の確認：JUnit 10件、翻訳処理のJavaScriptテスト3件が成功。Chromeで日英双方向の翻訳・原文表示・3人での参加・退室・再入室・サーバー再起動後の履歴を確認しました。翻訳準備に失敗した環境でも、原文を送受信できることを確認しています。AIによる検証で、本人・友人の使用確認とは別です。

公開準備としてHTTPS環境の通信元確認を追加し、JUnit 14件・JavaScriptテスト3件が成功しました。クラウドの実URLでの検証は未完了です。
